# 流程引擎前端改造说明

## 1. 概述

前端需要对接后台流程引擎 API，实现以下功能模块：
- **流程定义管理**: 创建、发布、管理流程模板
- **流程设计器**: 可视化拖拽设计流程（内嵌 warm-flow-ui）
- **发起流程**: 选择流程模板，填写表单，启动流程实例
- **待办任务**: 查看和处理分配给当前用户的审批任务
- **已办任务**: 查看已处理的审批历史
- **流程实例**: 查看所有流程实例的状态和进度

## 2. 认证对接

### 2.1 所有 API 请求需携带 Token

```javascript
// 在 axios 拦截器中统一设置
axios.interceptors.request.use(config => {
  const token = localStorage.getItem('accessToken')  // 或其他存储方式
  if (token) {
    config.headers.Authorization = `Bearer ${token}`
  }
  return config
})
```

### 2.2 流程设计器 Token 传递

流程设计器是独立 SPA（`/warm-flow-ui/index.html`），需要在 URL 中传递 Token：

```javascript
// 方式 1：在新窗口打开设计器
const token = localStorage.getItem('accessToken')
window.open(`/warm-flow-ui/index.html?token=${token}`)

// 方式 2：在 iframe 中嵌入
<iframe :src="`/warm-flow-ui/index.html?token=${token}`" />
```

```vue
  flowCode: '',
  businessId: '',
  message: ''

  const res = await getDefList({ isPublish: 1 })
  publishedDefs.value = res.data || []

    await startFlow(form.value)
    ElMessage.success('流程已发起')
    visible.value = false
    emit('success')

    ElMessage.error('发起失败: ' + e.message)
  } finally {
    loading.value = false
  }
```

```vue
<!-- views/flow/myTodo.vue -->

  <div class="my-todo">
    <!-- 搜索栏 -->

      <el-table-column label="状态" width="100">
        <template #default="{ row }">

          <el-button type="primary" size="small" @click="handleApprove(row)">审批</el-button>
          <el-button size="small" @click="handleDetail(row.instanceId)">详情</el-button>
        </template>
      </el-table-column>
    </el-table>

      v-model:current-page="queryParams.current"
      v-model:page-size="queryParams.size"
      :total="total"
      @change="getList"
    />

  </div>

<script setup>

import { getMyTodoList, getHisTaskList } from '@/api/flow'
import ApproveDialog from './components/ApproveDialog.vue'

const loading = ref(false)

const queryParams = ref({ current: 1, size: 10, flowName: '' })
const approveDialogRef = ref(null)

function statusType(status) {
  const map = { toDo: 'warning', pass: 'success', reject: 'danger', complete: 'info', termination: 'info' }
  return map[status] || 'info'
}

function statusLabel(status) {
  const map = { toDo: '待办', pass: '已通过', reject: '已驳回', complete: '已完成', termination: '已终止' }
  return map[status] || status
}

async function getList() {
  loading.value = true
  try {
    const res = await getMyTodoList(queryParams.value)
    taskList.value = res.data || []
    total.value = res.total || 0
  } finally {
    loading.value = false
  }
}

function handleApprove(row) {
  approveDialogRef.value.open(row)
}

async function handleDetail(instanceId) {
  const res = await getHisTaskList(instanceId)
  // 展示审批链路...
}

function handleQuery() { queryParams.value.current = 1; getList() }
function resetQuery() { queryParams.value = { current: 1, size: 10 }; getList() }

onMounted(() => getList())
</script>
```

### 5.4 审批弹窗组件

```vue
<!-- views/flow/components/ApproveDialog.vue -->
<template>
  <el-dialog title="审批" v-model="visible" width="500px">
    <el-descriptions :column="2" border>
      <el-descriptions-item label="流程名称">{{ task.flowName }}</el-descriptions-item>

    </el-descriptions>

    <el-form style="margin-top: 20px">
      <el-form-item label="审批意见">
        <el-input v-model="form.message" type="textarea" :rows="3" placeholder="请输入审批意见" />
      </el-form-item>
    </el-form>

    <template #footer>
      <el-button @click="visible = false">取消</el-button>
      <el-button type="danger" @click="handleReject">驳回</el-button>
      <el-button type="primary" @click="handlePass">通过</el-button>
    </template>
  </el-dialog>
</template>

<script setup>
import { ref } from 'vue'
import { passTask, rejectTask } from '@/api/flow'
import { ElMessage } from 'element-plus'

const emit = defineEmits(['success'])

const visible = ref(false)
const task = ref({})
const form = ref({ message: '' })

function open(row) {
  task.value = row
  form.value.message = ''
  visible.value = true
}

async function handlePass() {
  try {
    await passTask({ taskId: task.value.id, message: form.value.message })
    ElMessage.success('审批通过')
    visible.value = false
    emit('success')
  } catch (e) {
    ElMessage.error('操作失败: ' + e.message)
  }
}

async function handleReject() {
  try {
    await rejectTask({ taskId: task.value.id, message: form.value.message })
    ElMessage.success('已驳回')
    visible.value = false
    emit('success')
  } catch (e) {
    ElMessage.error('操作失败: ' + e.message)
  }
}

defineExpose({ open })
</script>
```

## 9. 注意事项

### 9.1 用户姓名字段

改造后所有列表接口都返回 `createByName` 字段，直接用于展示，无需前端额外查询用户信息。

### 9.2 待办/已办自动过滤

`myTodo` 和 `myDone` 接口已自动按当前登录用户过滤，前端无需传入用户 ID。

### 9.3 流程设计器 Token

流程设计器是独立 SPA，必须通过 URL 参数 `?token=xxx` 传递认证令牌。令牌过期后设计器 API 调用会返回 401，需重新打开。

### 9.4 权限标识

如果需要在节点的处理人配置中使用自定义权限标识：
- 角色格式：`role:dept_manager`
- 用户格式：`user:1`
- 标识与用户通过 `FlowUserContext` 自动生成的标识进行匹配

### 9.5 ID 类型

流程引擎的 ID 使用雪花算法生成，为 Long 类型（19位）。JSON 序列化时配置了 `@JsonSerialize(using = ToStringSerializer.class)` 转为字符串。前端接收时应作为字符串处理，避免 JS 精度丢失。
